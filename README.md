## Featured Projects

### CareerForge-Desktop

[Repository](https://github.com/Dibbo008/CareerForge-Desktop) | Java 21, JavaFX, SQLite, Google Gemini API

A desktop application for building professional resumes and cover letters, backed by a local SQLite database and enhanced with AI-generated content. It falls back to a local generator when no API key is available, so it works fully offline.

- Secure accounts with salted password hashing
- Dynamic resume builder with live preview and Classic and Modern templates
- AI-generated summaries and cover letters
- PDF and JSON export and import
- Interview preparation chart, role-based learning resource wizard, and a job application tracker
- Demonstrates abstraction, inheritance, polymorphism, generics, multithreading, asynchronous networking, and transactional database access
