## Featured Projects

### CareerForge: AI Resume & Career Builder

<a href="https://github.com/Dibbo008/CareerForge-Desktop">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=Dibbo008&repo=CareerForge-Desktop&theme=tokyonight&hide_border=true&bg_color=0f2027" alt="CareerForge-Desktop"/>
</a>

`Java 21` `JavaFX 21` `SQLite` `Jackson` `Apache PDFBox` `Gemini API`

A JavaFX desktop application for building professional resumes and cover letters, backed by a local SQLite database and enhanced with Google Gemini. When no API key is present, or a request fails, it falls back to a local generator, so the whole app works offline.

| | Feature |
| :-: | :-- |
| 🔐 | Secure accounts with salted password hashing |
| 📝 | Dynamic resume builder with live preview, Classic and Modern templates, light and dark themes |
| ✨ | AI-generated summaries and cover letters with automatic offline fallback |
| 📄 | PDF and JSON export and import, plus a searchable table of saved resumes |
| 🎯 | **To The Point**: a two-question wizard that maps a target role to hand-curated learning resources, with AI-assisted sector matching and no generated links |
| 📊 | Interview prep chart by sector and a job application tracker |

<details>
<summary><b>Engineering highlights</b></summary>

<br/>

| Concept | Implementation |
| :-- | :-- |
| Abstraction and inheritance | `Person` (abstract) → `Applicant` → `Student` |
| Generics | `GenericDAO<T>` for data access |
| Multithreading | 3-thread pool via `TaskManager` keeps the UI responsive |
| Asynchronous networking | `HttpClient.sendAsync()` with `CompletableFuture`; Gemini REST responses parsed with Jackson |
| Database design | Nine SQLite tables with cascade deletes, `PreparedStatement` everywhere, transactional resume writes |

</details>

`Verilog` `Xilinx Artix-7` `Basys 3` `Vivado`

A complete electronic voting system running on an FPGA.

- Voter authentication for valid IDs (0 to 9)
